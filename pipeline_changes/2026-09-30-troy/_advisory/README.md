# _advisory — claude.ai advisory outputs

Convention adopted 2026-09-14 (Najum accepted the Claude Code recommendation).

- This is the single permanent inbox for everything the claude.ai advisory project produces for the 2026-2027 Duplex Search Campaign.
- One dated subfolder per submission, named `YYYY-MM-DD <short label>` (example: `2026-09-14 session`). A submission is one claude.ai session's exports, even if the session ran over two days.
- Files keep the `CLAUDE.AI` prefix and the advisory's own numbering. Their numbers deliberately do NOT align with the main campaign numbering (both streams have a 28-31); the prefix plus the subfolder keeps them apart.
- Main-folder numbering belongs to the Claude Code workstream. Advisory material enters the numbered sequence only when adopted (example: main file 29a was rebased on advisory 31a).
- The claude.ai project cannot write to Dropbox by itself. Either it has the Dropbox connector and is given this exact path, or Najum exports and Claude Code files the batch on import.
- The claude.ai project should read this whole parent folder, not just the latest subfolder, so it sees its own earlier work.
